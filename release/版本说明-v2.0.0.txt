FGO 剧情文本监听器 v2.0.0

主要新增：
- 基于本机 codex-cli 的日文→简体中文自动翻译。
- 设置中可选择模型、推理强度、批量大小和悬浮译文。
- 默认 gpt-5.5 / low，已在当前 codex-cli 0.142.3 上完成真实端到端验证。
- 关卡、人物、日文原文、中文翻译四列双语 LOG。
- 同关卡上下文批量翻译；启动时自动补译历史 LOG，之后继续实时翻译。
- 来源校对的全局 FGO 术语 + 带证据、仅限当前关卡的动态记忆。
- 当前双语悬浮窗，点击 LOG 返回完整历史；支持只保留悬浮窗。
- Ctrl+C、复制全部、TXT 导出均输出双语内容。
- Hook 端口探测增加 8 秒超时，避免永久停在“正在部署监听运行时”。

注意：
- 需要本机已安装并登录 codex-cli（codex login status 可检查）。
- 当前 CLI 调用 gpt-5.6 系列会被要求升级；升级 CLI 后可以在设置里切换。
- 程序不会控制模拟器，不会点击选项，也不会修改原始 APK。
