FGO 剧情文本监听器 v2.5.0

1. 新增完整剧情预翻译
   - 进入剧情时只读获取 ScriptManager 已解析的消息数组。
   - 未来台词在后台翻译并保持隐藏；游戏实际播放到完全相同的日文后才显示缓存译文。
   - 未选择的分支不会提前出现在主历史或双语 LOG 中。
   - 预读取 Hook 不兼容时，原有实时 SetText/AddText 抓取仍可继续工作。

2. 新增人物口癖记忆
   - 红阎魔的 でち／まちゅ／まちぇん／まちた／まちょう 固定译为句尾“啾”。
   - 其他人物的候选口癖必须由同一人物至少 3 条不同剧情台词验证后才启用。
   - 普通日语语尾、普通中文语气词与冲突译法不会自动成为规则。

3. 扩展“更新术语与口癖”
   - 读取 Mooncell 结构化日中语音表。
   - 全量语料验证中，已排除把“マスター（御主）”、人物名和笑声误学成口癖的情况。
   - 更新仍采用快照、暂存冲突、原子切换及上一版回滚。

验证：26 项单元测试通过；hook.js 语法通过；Codex JSON Schema 实际翻译通过；
PyInstaller 构建完成且关键资源 SHA-256 与源码一致。
