# FGO 剧情翻译记忆策略

本项目把记忆分为两层，避免模型把一次猜测永久当作官方译名。

1. `fgo_glossary.json`：人工校对、带来源依据的全局硬术语。程序只读。
2. SQLite `quest_memory`：模型从当前关卡明确台词中提取的软记忆，只在同一关卡继续使用，且必须记录证据台词 ID。

翻译原则：完整、不漏行；人名和术语一致；保留语气、口癖、分行及选项编号；未知活动昵称采用保守译法，不冒充官方译名。

程序不读取用户的 Codex 对话历史，也不修改 `~/.codex/config.toml`。每批翻译使用临时、只读、无持久会话的 `codex exec --ephemeral`。
